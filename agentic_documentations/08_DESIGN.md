# Design System — Anti-Slop Rules

## Design goal

Commercial, editorial, calm, trustworthy education product.

Not:
- generic AI SaaS
- ChatGPT clone
- purple gradient dashboard
- glassmorphism template
- card soup
- excessive pills
- excessive rounded containers
- decorative AI sparkle
- meaningless metrics

## References

Use the design vocabulary and anti-slop philosophy of:
- https://impeccable.style/
- https://www.tasteskill.dev/

Use them as methodology references, not templates to copy.

## Visual character

Think:
premium editorial education
+
modern productivity software
+
language-learning workspace

## Typography

Typography should establish hierarchy before decoration.

Use:
- strong display heading
- highly readable body font
- compact UI text

Do not use many font families.

## Color

Use:
- neutral foundation
- one primary accent
- semantic success/warning/error colors

Avoid rainbow dashboards.

## Shape

Use a restrained radius scale.

Do not put every object inside a rounded card.

## Layout

Use:
- asymmetric compositions when useful
- strong content columns
- meaningful whitespace
- editorial hierarchy
- contextual side panels

Avoid:
- three identical cards everywhere
- centered everything
- cards inside cards
- giant empty hero sections

## Dashboard

Prioritize:
today's action
current estimated band
target
weakest area
next recommended activity

## Learning screen

Main content:
lesson/exercise

Secondary:
progress/context

Tertiary:
AI help when needed

## Exam screen

Minimal interface.
Timer.
Question navigation.
Answer area.
No distracting AI chat.

## Motion

Only meaningful transitions:
- route change
- feedback reveal
- recording state
- completion
- progress

Respect reduced-motion preferences.

## Accessibility

Keyboard-first.
Visible focus.
Semantic HTML.
High contrast.
No color-only signals.
Captions/transcripts for audio.

## Design review

Before shipping every major page:
- remove one unnecessary element
- inspect hierarchy
- inspect spacing
- inspect responsive behavior
- inspect empty states
- inspect loading states
- inspect error states
